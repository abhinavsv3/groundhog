What this showed
  - tasks mined from ordinary git history, with no hand-labelling
  - a pure refactor rejected, because its tests passed without the fix
  - an agent that fixed the bug and broke another module: not solved
  - an agent that edited the test to pass: not solved

  A FAIL_TO_PASS-only harness would have scored the middle two as fixes.
